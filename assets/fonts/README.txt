ضع هنا ملفات الخط العربي لعرض الحروف العربية بشكل صحيح.
Place Arabic-capable font files here so Arabic text renders correctly.

الملفات المطلوبة - Required files:
  - Cairo-Regular.ttf
  - Cairo-Bold.ttf   (اختياري - optional)

يمكنك تنزيل خط Cairo مجاناً من Google Fonts:
You can download the free Cairo font from Google Fonts:
  https://fonts.google.com/specimen/Cairo

بعد وضع الملفات سيتولى main.py تسجيل الخط تلقائياً.
Once the files are placed, main.py registers the font automatically.

ملاحظة: بدون هذا الخط ستظهر الحروف العربية كمربعات فارغة،
لكن اللغة الإنجليزية ستعمل بشكل طبيعي.
Note: Without this font Arabic letters appear as empty boxes,
but English works normally.
